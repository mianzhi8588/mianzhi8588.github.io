## Research question

Robot-control programs can pass nominal functional tests while still violating physical-safety constraints during execution. This project asks how those hidden failures can be surfaced, measured, and used to improve generated code.

## My contributions

- Built a simulation-based testbed for evaluating generated robot-control programs at the behavior level.
- Designed controlled tasks and evaluation procedures that separate functional completion from physical safety.
- Studying how execution evidence can support targeted revision without exposing the current benchmark, prompts, model comparisons, or numerical limits on this public page.
