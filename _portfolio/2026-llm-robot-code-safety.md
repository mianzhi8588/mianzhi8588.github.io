## Research question

Robot-control programs can pass nominal functional tests while still violating physical-safety constraints during execution. This project asks how those hidden failures can be surfaced, measured, and used to improve generated code.

## My contributions

- Built a MuJoCo testbed around a Franka Emika Panda manipulator for evaluating LLM-generated control programs.
- Designed tasks, safety oracles, and metrics covering collisions, velocity-limit violations, grasp failures, object drops, and restricted-workspace violations.
- Evaluated multiple language models under nominal, perturbed, and boundary conditions, separating task success from physical safety.
- Developing a defect-guided repair loop that uses violation reports and execution traces to revise unsafe code while preserving task functionality.
